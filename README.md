### 🩷 Hi! I'm Nightmarish Meatballs. 💚

If you have somehow landed here, hello! 

I'm a writer, and I write a serialised fictional story about a creepy pastel pink and green dystopia on Instagram under this username ([@nightmarishmeatballs](https://www.instagram.com/nightmarishmeatballs)).

I accompany the fictional stories I write with AI-generated images that allow readers to see what I'm seeing in my brain. It's fun! I've been working on the project since 2022. I've written about why and how I use AI [on my website](https://www.nightmarishmeatballs.com/faqs). 

GitHub might be the one and only place on the whole entire internet where I won't get harassed because I make silly AI images for fun to go along with my writing project, therefore ruining the entirety of art. I'm not sure. 🤔

The fictional world (which has been nicknamed “The Meatballverse”) is set in a pastel pink and green dystopia and is told in an “interview” style. The protagonist goes on a road trip, gets into sticky situations, and talks to the people who live and exist in this strange candy-coloured apocalypse. It doesn’t need to be read in any particular order, as it’s an open-world universe ([but you can start at the beginning if you want](https://www.nightmarishmeatballs.com/stories)!). 

LitRPG might be a term to describe it. There is no particular beginning, nor is there an ending. It’s just a story that keeps going.
